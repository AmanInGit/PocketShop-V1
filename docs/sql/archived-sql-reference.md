# Archived SQL Reference

This section stores SQL files that are useful for historical or reference review but are intentionally separated from the active application structure.

## Location

Archived scripts are stored in `docs/sql/archive/`.

## Why they are separated

- to keep the root repository structure cleaner
- to avoid mixing legacy SQL with the live product code
- to make examiner and reviewer navigation easier

## Important note

These files are preserved for understanding previous database work. They should not be assumed to represent an active automated migration pipeline unless explicitly promoted into one.
