# Troubleshooting Overview

This section is intentionally lightweight after the documentation cleanup.

## Scope

Use this area for operational issues such as:

- authentication setup problems
- OAuth redirect mismatches
- environment variable mistakes
- deployment configuration issues
- payment integration debugging

## Documentation rule

Troubleshooting material should live here inside `docs/` instead of being scattered across source folders or root-level markdown files.

## Recommended approach

When adding future troubleshooting documents:

1. group them by issue type
2. give each file a descriptive name
3. keep setup guidance separate from bug-fix guidance
